# @parapet/runtime

The browser runtime of Parapet Classic: everything between the deterministic simulation
(`@parapet/sim`) and the game itself. Nothing in here knows a specific level or menu; the game
(`@parapet/classic`) composes these parts. Imported by subpath, for example
`@parapet/runtime/render/Camera.ts`.

| Folder      | What lives there                                                                                                                                                                                                                                                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/`      | `Screen` / `ScreenStack` (stacked UI states), `GameLoop` (the original's fixed-step timing), `RunSession` (one run: world, input, replay, an optional ghost world raced in lockstep), `replayFile` (links and `.parapet-replay` files), `MissionFlow` (tutorial, briefing, flyover, ready, play).                               |
| `render/`   | `Viewport` (integer scaling, safe area), `SpriteSheet`, `SceneRenderer` (the k-file interpreter), `CharacterRenderer` (runners, skins, NPCs), `EchoSkin` + `EchoRenderer` (ghosts and rivals as holograms), `Camera` + `CameraTour`, `LevelRenderer` (sky, parallax, level art, markers), `Particles` (dust, birds, fireworks). |
| `anim/`     | `Animator`: the original's clip and keyframe state machine, verified against the oracle traces.                                                                                                                                                                                                                                 |
| `audio/`    | `MidiFile` (SMF parser), `Instruments` + `Synth` (a small Web Audio synthesiser), `MusicPlayer` (scheduling, looping, pause), `MusicDirector` (which track plays when).                                                                                                                                                         |
| `ui/`       | `layout` (breakpoints and rectangle helpers; screens re-flow on every resize), `Menu`, `MessageBox` (the original's paged box), `widgets`, `TextInputOverlay` (an HTML field over the canvas), `draw`, `theme`.                                                                                                                 |
| `text/`     | `BitmapFont`: the pre-rasterised fonts, with outlines and tabular digits for overlays.                                                                                                                                                                                                                                          |
| `i18n/`     | ICU-style messages with plural rules; dictionaries come from the apps.                                                                                                                                                                                                                                                          |
| `input/`    | `InputManager` (keyboard, gamepad, pointer; press-only semantics of the original; gestures delivered synchronously for clipboard and file access), `TouchControls`.                                                                                                                                                             |
| `storage/`  | `profile`: options, local records with input logs, mission progress; every entry versioned and validated.                                                                                                                                                                                                                       |
| `platform/` | `clipboard` (copy with fallbacks), `files` (download, file dialog, drop, paste).                                                                                                                                                                                                                                                |
| `content/`  | Types of the generated content files.                                                                                                                                                                                                                                                                                           |

Tests in `test/` run under Node without a DOM; the ones that need the extracted content skip
when it is absent.
