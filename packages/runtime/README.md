# @parapet/runtime

The browser runtime of Parapet Classic: everything between the deterministic simulation
(`@parapet/sim`) and the game itself. Nothing in here knows a specific level or menu; the game
(`@parapet/classic`) composes these parts. Imported by subpath, for example
`@parapet/runtime/render/Camera.ts`.

| Folder      | What lives there                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `app/`      | `Screen` / `ScreenStack` (stacked UI states), `GameLoop` (the original's fixed-step timing), `RunSession` (one run: world, input, replay, an optional ghost world raced in lockstep), `replayFile` (links and `.parapet-replay` files), `MissionFlow` (tutorial, briefing, flyover, ready, play).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `render/`   | `Viewport` (integer scaling, safe area; re-measured on every hint of a size change and checked once a second, applied at the start of a frame), `PlaceholderTiles` (the grey blocks of the Moves demos), `SpriteSheet`, `SceneRenderer` (the k-file interpreter), `CharacterRenderer` (runners, skins, NPCs), `Pose` + `Rig` (a pose as draw commands, the body's parts, sides and points), `Look` + `LookSheet` + `SkinLibrary` (outfits drawn as text over the skeleton: parts of any size, sides, gear on layers, a small sheet of what each outfit changes), `LookAtlas` + `rotsprite` (the artists' atlas and turned pictures), `fx/` (one particle system for the bosses' effects, afterimages, cloth), `Stage` (a boss's little world), `EchoSkin` + `EchoRenderer` (ghosts and rivals as holograms), `Sparks`, `Camera` + `CameraTour`, `LevelRenderer` (sky, parallax, level art, markers), `Particles` (dust, birds, fireworks). |
| `anim/`     | `Animator`: the original's clip and keyframe state machine, verified against the oracle traces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `audio/`    | `MidiFile` (SMF parser), `Instruments` + `Synth` (a small Web Audio synthesiser), `MusicPlayer` (scheduling, seamless looping over two synthesisers, fades on every change), `MusicDirector` (which track plays when, the volume curve), `Score` (music written as a text score), `LoudnessMeter` (BS.1770 loudness of a track rendered offline; the measured table levels the tracks).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `ui/`       | `layout` (breakpoints and rectangle helpers; screens re-flow on every resize), `Menu` (centred or left labels, sliders, press on release, drag and wheel scrolling), `press` (press feedback shared by everything tappable), `Button` / `BackButton`, `TileGrid`, `TextScroller` (long text that scrolls by itself and by hand), `ShowcaseBox` (the box of the character select and the Moves menu), `Toast`, `MessageBox` (the original's paged box; long pages split), `widgets`, `TextInputOverlay` (an HTML field over the canvas), `draw`, `theme`.                                                                                                                                                                                                                                                                                                                                                                                   |
| `text/`     | `BitmapFont`: the pre-rasterised fonts, with outlines and tabular digits for overlays.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `i18n/`     | ICU-style messages with plural rules; `locales` groups the per-language folders, `check` compares them with English (keys, arguments, font coverage).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `input/`    | `InputManager` (keyboard, gamepad, pointer; press-only semantics of the original; gestures delivered synchronously for clipboard and file access), `TouchControls`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `storage/`  | `profile`: options, local records with input logs, mission progress; every entry versioned and validated.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `platform/` | `clipboard` (copy with fallbacks), `files` (download, file dialog, drop, paste), `fullscreen` (full screen, the installed app, iOS), `HistoryGuard` (the Back button kept inside the game).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `moves/`    | The Moves menu's demos: `demoLevel` (levels written as text), `MoveDemo` (a demo's world, presses and the check that it shows its move), `moveKeys`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `content/`  | Types of the generated content files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

Tests in `test/` run under Node without a DOM; the ones that need the extracted content skip
when it is absent.
